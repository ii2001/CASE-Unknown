# Game design

The loop is briefing → explore → discover access clue → open deeper location → interview → compare → accuse → reveal. “Blackout Protocol” has three suspects, four locations, seven clues, four critical clues, one false alibi and one red herring. The backup-key record unlocks the server room. Evidence is deterministic and cannot be duplicated. A wrong accusation ends the case, preserving stakes.

Progressive disclosure keeps instructions contextual: locked navigation explains its prerequisite; location cards show only visited descriptions; the board begins empty; quick actions teach the verbs. Images establish mood without encoding facts required for solution.
